Trabalhando com Pseudo-classe

São usadas para definir um elemento com um estado especial

Serve para:

  • Estilizar um elemento quando um usuário passa o mouse sobre ele
  • Estilizar o link visitado e o não visitado de forma diferente.
  • Estilizar um elemento quando ele recebe o foco.

PSEUDO-CLASSE

Pseudo Elemento

Um pseudo-elemento é usado para estilizar partes especificas de um elemento.

Por exemplo:

  • Estilize a primeira letra ou linha de um elemento.
  • Insira conteúdo antes ou depois do conteúdo de um elemento.

NOTA: 0 ::frist-line só pode ser aplicado a um elemento de nivel de bloco.

As seguintes propriedades se aplicam ao :: frist-line:

  • Propriedade de fonte
  • Propriedade de cor
  • Propriedade de fundo
  • Espaçamento entre as palavras
  • Espaçamento entre as letras
  • Decoração do texto
  • Alinhamento vertical
  • transformação de texto
  • Altura de linha
